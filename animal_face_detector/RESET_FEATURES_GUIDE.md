# 🔄 초기화 기능 완전 가이드

## ✨ **새로 추가된 초기화 기능들**

### 🎯 **4가지 초기화 방법**

#### 1️⃣ **원본 복원** (기존 기능 개선)
- **버튼**: "원본 복원"
- **단축키**: `Ctrl+R`
- **메뉴**: 초기화 → 원본 복원
- **기능**: 현재 이미지를 원본 상태로 되돌림
- **사용 시기**: 처리 결과가 마음에 들지 않을 때

#### 2️⃣ **설정 초기화** (새로 추가)
- **버튼**: "설정 초기화"
- **단축키**: `Ctrl+Shift+R`
- **메뉴**: 초기화 → 설정 초기화
- **기능**: 모든 설정값을 기본값으로 리셋
- **초기화 항목**:
  - YOLO 모델: n (나노)
  - 신뢰도: 0.5
  - 경계선 방법: Canny
  - Canny 임계값: Lower 50, Upper 150

#### 3️⃣ **전체 초기화** (새로 추가)
- **버튼**: "전체 초기화"
- **단축키**: `Ctrl+Shift+A`
- **메뉴**: 초기화 → 전체 초기화
- **기능**: 이미지 + 설정 + 캔버스 모두 초기화
- **안전장치**: 확인 대화상자 표시
- **초기화 항목**:
  - 모든 이미지 데이터 삭제
  - 캔버스 완전 정리
  - 모든 설정값 기본값으로
  - 임시 파일 정리

#### 4️⃣ **캔버스 정리** (내부 함수)
- **기능**: 이미지 표시 영역만 깨끗하게 정리
- **사용**: 내부적으로 전체 초기화 시 호출

## 🎮 **새로 추가된 컨트롤**

### 📋 **메뉴바 시스템**
```
📁 파일
├── 이미지 열기 (Ctrl+O)
├── 폴더 선택
├── ─────────────────
├── 결과 저장 (Ctrl+S)
├── ─────────────────
└── 종료

⚙️ 처리
├── 동물 얼굴 탐지 (F1)
├── 경계선 탐지 (F2)
└── 결합 처리 (F3)

🔄 초기화
├── 원본 복원 (Ctrl+R)
├── 설정 초기화 (Ctrl+Shift+R)
├── ─────────────────
└── 전체 초기화 (Ctrl+Shift+A)

❓ 도움말
├── 키보드 단축키 (F12)
└── 프로그램 정보
```

### ⌨️ **키보드 단축키 (전체 목록)**
```
파일 관련:
  Ctrl+O : 이미지 열기
  Ctrl+S : 결과 저장

초기화 관련:
  Ctrl+R : 원본 이미지로 복원
  Ctrl+Shift+R : 설정 초기화
  Ctrl+Shift+A : 전체 초기화

기능 실행:
  F1 : 동물 얼굴 탐지
  F2 : 경계선 탐지  
  F3 : 결합 처리 (얼굴+경계선)

도움말:
  F12 : 키보드 단축키 도움말
```

## 💡 **초기화 시나리오별 가이드**

### 🔧 **상황 1: 설정값만 리셋하고 싶을 때**
```
문제: 여러 설정을 만지다가 어떤 값으로 했는지 기억 안남
해결: "설정 초기화" 버튼 클릭 또는 Ctrl+Shift+R
결과: 이미지는 그대로, 설정만 기본값으로
```

### 🖼️ **상황 2: 이미지만 원본으로 되돌리고 싶을 때**
```
문제: 처리 결과가 마음에 들지 않음
해결: "원본 복원" 버튼 클릭 또는 Ctrl+R
결과: 이미지만 원본으로, 설정은 그대로 유지
```

### 🧹 **상황 3: 완전히 새로 시작하고 싶을 때**
```
문제: 모든 것을 깨끗하게 정리하고 새 작업 시작
해결: "전체 초기화" 버튼 클릭 또는 Ctrl+Shift+A
확인: "정말 초기화하시겠습니까?" → 예
결과: 완전히 깨끗한 상태로 초기화
```

### ⚡ **상황 4: 빠른 작업 전환**
```
시나리오: 여러 이미지를 연속으로 처리
방법: 
1. 첫 번째 이미지 처리 완료
2. Ctrl+S로 저장
3. Ctrl+Shift+A로 전체 초기화
4. Ctrl+O로 새 이미지 로드
5. 반복
```

## 🚀 **향상된 워크플로우**

### 📈 **효율적인 작업 순서**
```
1단계: 이미지 로드 (Ctrl+O)
2단계: 필요시 설정 조정
3단계: 처리 실행 (F1/F2/F3)
4단계: 결과 저장 (Ctrl+S)
5단계: 다음 작업을 위한 초기화
   - 같은 설정: Ctrl+R (원본 복원)
   - 다른 설정: Ctrl+Shift+A (전체 초기화)
```

### 🔄 **반복 작업 최적화**
```
같은 설정으로 여러 이미지 처리:
1. 설정 한 번만 조정
2. 이미지별로: 로드 → 처리 → 저장 → 원본복원
3. 설정은 유지되므로 빠른 처리 가능

다른 설정으로 실험:
1. 이미지 로드
2. 설정1로 처리 → 저장
3. Ctrl+Shift+R (설정 초기화)
4. 설정2로 처리 → 저장
5. 비교 분석
```

## ⚠️ **주의사항**

### 🛡️ **안전장치**
- **전체 초기화**: 확인 대화상자로 실수 방지
- **설정 초기화**: 완료 메시지로 확인
- **원본 복원**: 원본이 없으면 경고 표시

### 💾 **데이터 보호**
- 초기화 전 중요한 결과는 반드시 저장
- 전체 초기화는 되돌릴 수 없음
- 임시 파일은 자동으로 정리됨

## 🎯 **초기화 기능 활용 팁**

1. **빠른 테스트**: F12로 단축키 확인 후 키보드만으로 작업
2. **설정 실험**: 설정 초기화로 언제든 기본값으로 돌아가기
3. **배치 작업**: 전체 초기화로 각 이미지 독립적으로 처리
4. **오류 복구**: 문제 발생 시 전체 초기화로 깨끗한 상태 복구
