# 동물 얼굴 & 경계선 탐지 GUI 사용법

## 🎯 주요 기능

### 1. 동물 얼굴 탐지
- **YOLO 모델 선택**: n(빠름), s(균형), m(정확), l(매우정확)
- **신뢰도 조정**: 0.1 ~ 0.9 (기본값: 0.5)
- **실시간 탐지**: 바운딩 박스와 동물 종류 표시

### 2. 경계선 탐지
- **Canny**: 가장 일반적인 경계선 탐지 (추천)
- **Sobel**: X, Y 방향 그라디언트 기반
- **Laplacian**: 2차 미분 기반 경계선
- **Scharr**: Sobel의 개선된 버전

### 3. 결합 처리
- 동물 얼굴 탐지 + 경계선 탐지를 동시에 처리
- 얼굴은 빨간 박스, 경계선은 노란색으로 표시

## 🚀 사용 방법

### 1단계: 프로그램 실행
```bash
cd animal_face_detector
python gui_detector.py
```

### 2단계: 이미지 로드
1. **"이미지 열기"** 버튼 클릭
2. 동물 사진 선택 (.jpg, .png, .bmp 등)
3. 이미지가 오른쪽 캔버스에 표시됨

### 3단계: 기능 선택

#### 동물 얼굴만 탐지
1. YOLO 모델 선택 (n=빠름, s=권장, m=정확)
2. 신뢰도 조정 (0.5 권장)
3. **"얼굴 탐지 실행"** 클릭

#### 경계선만 탐지
1. 탐지 방법 선택 (Canny 권장)
2. Lower/Upper Threshold 조정
3. **"경계선 탐지 실행"** 클릭

#### 둘 다 적용
1. **"얼굴 + 경계선"** 버튼 클릭
2. 자동으로 두 기능 모두 적용

### 4단계: 결과 저장
1. **"결과 저장"** 버튼 클릭
2. 저장 위치와 파일명 지정
3. .jpg 또는 .png 형식으로 저장

## ⚙️ 파라미터 가이드

### 동물 얼굴 탐지
- **신뢰도 0.3**: 많은 후보 탐지 (false positive 증가)
- **신뢰도 0.5**: 균형잡힌 설정 (권장)
- **신뢰도 0.7**: 확실한 것만 탐지 (놓치는 경우 증가)

### 경계선 탐지 (Canny)
- **Lower: 50, Upper: 150**: 일반적인 설정
- **Lower: 30, Upper: 100**: 더 많은 경계선 탐지
- **Lower: 100, Upper: 200**: 강한 경계선만 탐지

## 🎨 결과 해석

### 동물 얼굴 탐지 결과
- **파란색 박스**: 동물 전체 몸
- **빨간색 박스**: 추정 얼굴 영역
- **텍스트**: 동물 종류 + 신뢰도

### 경계선 탐지 결과
- **흰색 선**: 탐지된 경계선
- **검은 배경**: 경계선이 없는 영역

### 결합 처리 결과
- **파란/빨간 박스**: 얼굴 탐지 결과
- **노란색 선**: 경계선
- 두 정보를 한 번에 확인 가능

## 💡 팁 & 트릭

1. **이미지 품질**: 고해상도 이미지일수록 더 정확한 탐지
2. **조명**: 밝고 명확한 이미지에서 더 좋은 결과
3. **동물 크기**: 너무 작은 동물은 탐지가 어려움
4. **배경**: 복잡한 배경보다 단순한 배경이 유리

## ❗ 문제 해결

### 얼굴이 탐지되지 않는 경우
1. 신뢰도를 0.3으로 낮춰보기
2. 더 큰 YOLO 모델(s→m→l) 사용
3. 이미지 품질 확인

### 경계선이 너무 많은 경우
1. Canny Upper Threshold 증가
2. Lower Threshold 증가
3. 다른 경계선 방법 시도

### 프로그램이 느린 경우
1. YOLO 모델을 n(nano)으로 변경
2. 이미지 크기가 너무 크면 작은 이미지로 테스트
3. 백그라운드 실행 중인 다른 프로그램 종료
