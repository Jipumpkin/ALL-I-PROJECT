# 📸 이미지 데이터 디렉토리

이 폴더에 합성에 사용할 이미지들을 저장하세요.

## 📋 필요한 파일들

### 테스트용 이미지 (예제)
- `animal.jpg` - 동물 사진 (유기동물 또는 반려동물)
- `custom_space.jpg` - 커스텀 공간 이미지 (거실, 주방, 욕실 등)

### 실제 사용시
- Node.js 백엔드에서 업로드된 이미지들을 이 폴더에 임시 저장
- 또는 절대 경로로 직접 CLI에 전달

## 🎯 이미지 요구사항

### 동물 이미지
- **형식**: JPG, PNG
- **크기**: 최소 512x512, 권장 1024x1024 이상
- **품질**: 선명하고 밝은 이미지
- **각도**: 정면 또는 측면이 보이는 각도
- **배경**: 단순한 배경이 더 좋음

### 공간 이미지  
- **형식**: JPG, PNG
- **크기**: 최소 512x512, 권장 1024x1024 이상
- **조명**: 자연광이 있는 밝은 공간
- **구도**: 동물이 들어갈 여유 공간이 보이는 구도
- **용도**: 거실, 주방, 욕실, 정원 등 케어 활동에 적합한 공간

## 💡 팁

1. **고품질 이미지 사용**: 더 좋은 합성 결과를 위해
2. **다양한 각도 시도**: 여러 각도의 공간 사진으로 테스트
3. **조명 매치**: 비슷한 조명 조건의 이미지들이 더 자연스러움
4. **파일 크기 최적화**: 너무 큰 이미지는 처리 시간이 오래 걸림

---

**⚠️ 주의사항**: 
- 저작권이 있는 이미지 사용 시 주의
- 개인정보가 포함된 이미지 사용 금지
- 테스트 후 불필요한 이미지는 삭제 권장
